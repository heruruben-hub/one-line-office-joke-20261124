## The entry

`main.py` writes exactly one original one-line joke about office life — 97 characters — to `/output/entry.txt`:

```text
I asked for a raise and got a pizza party instead — apparently my landlord now accepts pepperoni.
```

One line, nothing else. The setup is the familiar office let-down — a raise
request answered with a pizza party — and the punchline lands in the last few
words, where the pizza stops being a party and starts being the pay rise.

## Run

```sh
python3 main.py
```
